・定理 5.3（フルビッツの安定判別法）：an > 0 のとき、すべての主座小行列式 Δk > 0 であることが安定の必要十分条件
・必要条件：すべての係数が同符号で存在すること。3次以上ではこれだけでは不十分
・2次 s²+a₁s+a₀：条件は a₁ > 0 かつ a₀ > 0（全係数が正）
・3次 s³+a₂s²+a₁s+a₀：全係数が正、かつ a₂a₁ > a₀（これが Δ₂ > 0 に対応）
・ラウスの安定判別法と本質的に同じ条件を与える。ラウス表の第1列が正であることと、主座小行列式が正であることは等価
・Δk のどれかが 0 になるのが安定限界。虚軸上に根が来て持続振動が生じる
